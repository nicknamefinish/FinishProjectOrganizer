Como instalar

  1. Baixe o arquivo FinishOrganizer-win-Setup.exe pelo botão acima.
  2. Abra o arquivo. Ele instala em segundos, sem pedir senha de administrador.
  3. Pronto! O Finish abre sozinho e cria um atalho na Área de Trabalho e no Menu Iniciar.

Ao abrir pela primeira vez, o Windows pode mostrar “O Windows protegeu o computador”. Clique em Mais informações → Executar assim mesmo. Isso acontece com programas novos que ainda não têm assinatura digital.
